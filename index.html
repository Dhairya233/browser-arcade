About online rooms

Online rooms are peer-to-peer. The host's browser runs the game and everyone else connects to it, so the host has to keep their tab open. If the host closes it, the game ends.

Some school, work and mobile networks block peer-to-peer connections. If a friend cannot join, try another network or a different browser, and check that the room code is typed correctly.

To invite someone, copy the room link from the lobby. Opening it takes them straight to the join screen.
